# Property Listing Quality Auditor

A real-estate quality agent that checks draft property listings for missing information, contradictions, and unsupported claims.

## Workflow

1. Receive the draft listing and available property details.
2. Apply completeness and consistency checks.
3. Explain defects and required verification.
4. Return the corrected checklist to an authorized reviewer.

## Passport Files

The root folder contains the three required passport files.
